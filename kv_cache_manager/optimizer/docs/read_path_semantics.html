Optimizer 读路径行为语义

本表只描述 read/get 路径。

阶段 条件 状态更新 层间行为 命中统计
读前 TTL 处理 每次 read/get 开始前 移除 TTL 过期 location 只做逻辑过期；空节点物理清理延迟到本次请求结尾 进入后续前缀查询
前缀查询 沿 radix tree 按输入 keys 连续匹配 连续命中的 block 进入后续 read hit 处理 遇到 miss、evicted block、key 不连续后结束本次前缀匹配 只统计连续命中前缀
read hit block block 存在且未过期/未驱逐 block access_count += 1，last_access_time = now 进入 tier 读命中处理 计入当前请求 hit
命中最高层 tier 按 tier 顺序找到第一个持有该 block 的 tier 该 tier access_count += 1，last_access_time = now touch 该 tier 的 eviction policy，并记录 READ_TOUCH 计入该 tier hit
向下 access propagation 低层已有副本，且相邻 edge 的 access_propagation_enabled = true 低层 tier last_access_time = now 只刷新已有低层副本冷热，不创建新副本，并记录 READ_TOUCH 命中归属保持为最高命中 tier
read promote block 命中低层 新高层副本初始化 tier stat，write_touch_count = 0 copy 到经过的高层并记录 ENTER_TIER；容量驱逐记录 LEAVE_TIER/FINAL_EVICT，engine pool-source 层驱逐可触发 cascading 写 pool 命中统计保持为本次原始 read hit
hierarchical engine hit hierarchical read 先查 engine-local 且命中 engine 内部按 engine_read_query_type 查询并更新 engine 命中 index 集合作为 local mask，后续 P2P 和 storage pool 都不重复计这些 block 计入 LocalHit
P2P read engine-local 未命中的 block，且配置了 p2p_read_flows 按配置顺序查询同集群 peer 的指定 tier；可按 peer_read_touch_enabled 刷新 peer tier 访问时间 P2P 命中回填当前 engine；回填是 promote/fill，不产生 write touch 计入 PeerHit
storage pool read hierarchical read 的完整 keys 进入 storage pool local/peer 都未命中的 block 按 trace query_type 在 pool 中查询；local/peer 已命中 block 由 local_read_touch_enabled 决定是否刷新 pool 访问时间 prefix_match 下 local/peer hit index 可让 prefix 继续向后推进，但不重复计 pool hit；batch_get 下逐 block 独立查询 pool 命中计入 RemoteHit
storage pool hit 回填 engine storage pool hit 以完整命中 prefix 回填 engine，已有 engine block 不做 write touch，新回填 block 的 write_touch_count = 0 回填 engine 最高层；若回填触发 engine pool-source 层驱逐，且 storage pool flow 是 cascading，evicted sequence 写入 pool 命中统计保持为 storage pool RemoteHit
读后统一清理 本次 read/promote 结束后 清理本次 TTL/容量驱逐后已经没有 location 的 block 统一裁剪空 block 和空叶子节点 生命周期淘汰信息在最终驱逐时记录
