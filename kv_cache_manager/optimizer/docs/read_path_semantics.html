Optimizer 读路径行为语义

本表只描述 read/get 路径。

阶段 条件 状态更新 层间行为 命中统计
读前清理 每次 read/get 开始前 清理 TTL 过期 block 和空 location 只删除已过期数据 进入后续前缀查询
前缀查询 沿 radix tree 按输入 keys 连续匹配 连续命中的 block 进入后续 read hit 处理 遇到 miss、evicted block、key 不连续后结束本次前缀匹配 只统计连续命中前缀
read hit block block 存在且未过期/未驱逐 block access_count += 1，last_access_time = now 进入 tier 读命中处理 计入当前请求 hit
命中最高层 tier 按 tier 顺序找到第一个持有该 block 的 tier 该 tier access_count += 1，last_access_time = now touch 该 tier 的 eviction policy 计入该 tier hit
向下 access propagation 低层已有副本，且相邻 edge 的 access_propagation_enabled = true 低层 tier last_access_time = now 只刷新已有低层副本冷热，不创建新副本 命中归属保持为最高命中 tier
read promote block 命中低层，且向高层 edge 的 promote_enabled = true 新高层副本初始化 tier stat copy 到经过的高层，可能触发容量检查和驱逐 命中统计保持为本次原始 read hit
hierarchical engine hit hierarchical read 先查 engine-local 且命中 engine 内部按普通 optimizer read 更新 engine 命中 prefix 作为 local mask 传入 storage pool 计入 LocalHit
storage pool read hierarchical read 的完整 keys 进入 storage pool engine miss suffix 按普通 optimizer read 更新；engine hit prefix 由 local_read_touch_enabled 决定是否刷新 pool 访问时间 engine hit prefix 使用 local mask；engine miss suffix 在 pool 中查询 suffix 命中计入 RemoteHit
storage pool hit 回填 engine storage pool hit，且 storage_pool_flow.promote_enabled = true engine 写入新副本 回填 engine；若 engine eviction 且 storage pool flow 是 cascading，evicted sequence 写入 pool 命中统计保持为 storage pool RemoteHit
