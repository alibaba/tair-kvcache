Optimizer 写路径层间流动语义

本表描述 write/insert、write touch、驱逐下沉、selective 下写，以及 hierarchical engine 到 storage pool 的写入流动。

阶段 条件 状态更新 层间行为 统计/后续处理
写前清理 每次 write 开始前 清理 TTL 过期 block 和空 location 只删除已过期数据 进入本次写入
写入新 block radix tree 中不存在该 key，或该 block 已被完全驱逐 初始化 block writing_time、last_access_time、TTL；入口 tier 初始化 tier stat 按相邻 edge 的 write_mode 决定初始落哪些 tier 计入 newly inserted blocks，记录 block birth
write_through 初始写 相邻 edge write_mode = write_through 入口 tier 是新写入；后续 tier 是 copy 语义，按当前时间初始化 tier stat 沿连续 write-through edge 写到所有经过的低层 每个落地 tier 注册到自己的 eviction policy
cascading 初始写 相邻 edge write_mode = cascading 只在入口 tier 初始化写入状态 不在写入时落下一层；后续由容量驱逐触发下沉 低层没有副本时不会占用容量
write_through_selective 初始写 相邻 edge write_mode = write_through_selective 只在入口 tier 初始化写入状态 不在初始写入时落下一层；后续由 write touch 阈值触发下写 下写阈值由 selective_write_threshold 控制
写命中已有 block 写入 key 已存在且仍有 location block last_access_time = now；命中的已有 tier 执行 write touch 入口 tier 已有副本时 touch 入口 tier；入口 tier 不存在时重新写入入口 tier 计入 write hit，不计 newly inserted
write touch 某 tier 已有该 block，并且本次写路径触达该 tier 该 tier last_access_time = now，write_touch_count += 1 刷新 eviction policy 中该 tier 的冷热位置 write touch 不改变 writing_time
向下 write propagation 低层已有副本，且相邻 edge 的 write_propagation_enabled = true 对所有连续可达的低层已有副本做 write touch 只 touch 已有副本，不创建低层新副本 某条 edge 关闭后，更低层也不再传播
selective 下写 某 tier 的 write_touch_count >= selective_write_threshold，且该 edge 是 selective 被复制到下一层的 tier 使用当前时间初始化，write_touch_count = 1 复制到下一层；若后续 edge 是 write-through，则继续写穿到连续低层 由 write touch 触发，不由 read 触发
写后容量检查 本次 write/下写结束后 驱逐策略按各 tier 当前冷热选择 victim 分层模式按 tier 顺序从高层到低层检查容量 驱逐出的路径进入 eviction bookkeeping
cascading 驱逐下沉 某 tier 发生容量驱逐，且到下一层 edge 是 cascading 下一层不存在该 block 时复制到下一层；已有则保持已有副本 下沉后若后续 edge 是 write-through，可继续写穿到连续低层 最后一层驱逐后 location 为空，才进入真正淘汰清理
写穿/ selective edge 上的驱逐 某 tier 发生容量驱逐，edge 不是 cascading 只删除被驱逐 tier 的 location 不做驱逐下沉 block 仍可能在其他 tier 存活

Hierarchical engine → storage pool

storage_pool_flow.write_mode engine 写入 storage pool 写入 storage pool 已有副本 说明
write_through trace write 先写 engine 本次写入实际传到多层 engine 最后一层，或非分层 engine shared 层的 block 写入 storage pool；包含直接写穿和 engine 内部驱逐下沉到最后一层的 block shadow_write_touch_enabled 控制是否对 pool 已有副本做 write touch 用于模拟 engine 写入同时进入 pool 的场景
cascading trace write 只写 engine engine 侧完全驱逐出去的 block 写入 storage pool 驱逐下沉写入 pool 时不做已有副本 touch 用于模拟 engine 本地缓存先承接，淘汰后再进入 pool
write_through_selective trace write 只写 engine 本次写入触达到 engine pool-source 层，且写触达次数达到阈值后，将对应 prefix 写入 storage pool shadow_write_touch_enabled 控制写入 pool 时已有副本是否 write touch 用于减少直接写入 pool 的放大，只让重复写触达的 block 进入 pool
pool 内部多层 engine 只决定哪些 keys 进入 pool 写路径 pool 内部按自己的 tier_flows 决定写穿、驱逐下沉和 selective pool 内部已有副本的 write touch 仍由 pool 自己的写路径执行 engine → pool 的 flow 不替代 pool 内部多层 flow
